# Cola Tile Assets

The game is currently configured to use these six files:

- `focus.png`
- `smile.png`
- `naughty.png`
- `lick.png`
- `bigsmile.png`
- `sleepy.png`

Level-specific objective assets:

- `bone.png`: Level 2 fixed treat objective
- `muddycola.png`: Level 3 mud goal icon
- `ball.png`: Level 4 gravity-affected fetch ball objective, not used for random Cola tile refills

The paths are configured in `src/config/level.js`.
